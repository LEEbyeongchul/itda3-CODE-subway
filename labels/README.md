# 검증셋 라벨링

목적: 파이프라인 정확도를 **숫자로** 재고, 어떤 유형에서 틀리는지 알아내기. 가산점(직접 라벨링 5점) 증빙도 겸함.
1·2차 1,000장 (저화질 400 · 중간 250 · 고해상도 350, 해상도 층화 무작위 추출) + 3차 나머지 2,352장 = 전수 3,352장. 1차 500장은 측정용, 2차 500장은 튜닝용, 3차는 추가 검증·본선용.

## 준비 (한 번만)

1. `git pull`
2. 데이터셋 `images.zip` 을 저장소 루트에 풀어 `images/000001.jpg …` 가 되게 (gitignore 라 각자 받아야 함)
3. Python 3.10 + Pillow 만 있으면 됨 (venv 세팅했으면 그걸로)

## 라벨링

내 블록 번호와 이름으로 실행:

```bash
python notebooks/label.py --block 1 --name 홍길동
```

| 담당 | 1차 (9/9 정오까지) | 2차 (9/9 저녁 ~ 9/10 오전) |
| --- | --- | --- |
| 승아 | `python notebooks/label.py --block 1 --name 승아` | `python notebooks/label.py --block 6 --name 승아` |
| 서현 | `python notebooks/label.py --block 2 --name 서현` | `python notebooks/label.py --block 7 --name 서현` |
| 민섭 | `python notebooks/label.py --block 3 --name 민섭` | `python notebooks/label.py --block 8 --name 민섭` |
| 서영 | `python notebooks/label.py --block 4 --name 서영` | `python notebooks/label.py --block 9 --name 서영` |
| 병철 | `python notebooks/label.py --block 5 --name 병철` | `python notebooks/label.py --block 10 --name 병철` |

**3차 (전수, 1·2차 끝난 뒤)** — 나머지 2,352장을 블록 11~15로 나눔. 인당 약 470장, 장당 15초면 2시간.

| 담당 | 3차 |
| --- | --- |
| 승아 | `--block 11` |
| 서현 | `--block 12` |
| 민섭 | `--block 13` |
| 서영 | `--block 14` |
| 병철 | `--block 15` |

블록당 **100장**, 1인 2블록 = 200장. 각 블록은 저화질·중간·고해상도가 섞여 있음.

- **1차 블록(1~5)은 9/9 정오까지** — 이걸로 오후에 정확도 측정·오류 분석을 돌림
- **2차 블록(6~10)은 9/9 저녁~9/10 오전** — 튜닝용. 1차와 분리해 두면 "안 본 데이터에서 X%"를 말할 수 있음
- **50장 하고 한 번 쉬세요.** 연속 50분이면 뒤쪽 라벨 품질이 떨어집니다. 중간에 꺼도 이어서 됩니다

창이 뜨면 **포장에 찍힌 그대로** 입력하고 Enter. 점·슬래시·2자리 연도 등 **형식을 바꾸지 말 것** — 포장의 표기 형식 자체가 분석 데이터입니다. 시간(`09:45`)·`까지`·LOT 번호는 치지 않고 **날짜 숫자만**. 예:

| 포장에 보이는 것 | 입력 | 저장되는 값 |
| --- | --- | --- |
| 소비기한 2027.06.26 까지 | `2027.06.26` | 2027-06-26 |
| 2026/02/17 또는 2026-02-17 | `2026/02/17` (구분자 그대로) | 2026-02-17 |
| 20260217 (점 없이 붙어 있음) | `20260217` | 2026-02-17 |
| 제조 25.06.26 / 소비 26.06.25 | `26.06.25 2` | 2026-06-25, 태그 2 |
| BBD: 20/05/2026 | `20/05/2026` | 2026-05-20 (연도 뒤면 자동 일/월/년) |
| BEST BEFORE (DDMMYY) 050926 | `050926 d` | 2026-09-05 |
| 30 12 23 (이탈리아 각인) | `30 12 23 d e` | 2023-12-30 |
| 10.14 09:45 (연도 없음) | `10.14` | NONE-10-14 |
| 賞味期限 2027.7 (일 없음, 일본 제품) | `2027.7` | 2027-07-NONE |
| BBE NOV 29 2021 (영문 월 이름) | `NOV 29 2021` (BBE/EXP 는 빼고) | 2021-11-29 |
| 날짜 자체가 없음 | `NONE` | NONE |
| 사람도 못 읽음 | `s` | NONE, 태그 s |

**규칙 (운영진 확정)**
- 날짜가 여러 개면 **소비기한(가장 늦은 것)** 만 적고 태그 `2`
- 연도가 없으면 연도만 NONE (`10.14` 처럼 월.일만 입력)
- 연도가 뒤에 있으면 일/월/년으로 읽음 → 도구가 자동 처리. 2자리·6자리인데 일이 먼저면 `d` 태그

**애매할 때 판단 규칙** — 사람마다 다르게 적으면 라벨이 쓸모없어지므로 아래대로 통일

| 상황 | 이렇게 | 예 |
| --- | --- | --- |
| 제조일자만 있고 소비기한이 없음 | 그 날짜를 적음 (운영진: 날짜 하나면 소비기한으로 간주) | `2025.06.18` |
| 제조·소비 둘 다 있는데 어느 게 뭔지 표시 없음 | 더 늦은 날짜 + 태그 `2` | `26.06.25 2` |
| 유통기한과 소비기한이 둘 다 찍힘 | 더 늦은 날짜 + 태그 `2` | |
| `2020.12.28 부터 ~ 2021.12.27 까지` | **까지** 쪽 + 태그 `2` | `2021.12.27 2` |
| 날짜 옆에 시간(`16:35`)·로트(`A03`) | 무시하고 날짜만 | `2027.06.26` |
| 손글씨·스티커로 덧붙인 날짜 | 인쇄와 똑같이 취급 | |
| 앞면만 찍혀서 날짜가 안 보임 | `NONE` | |
| 숫자가 흐려서 6인지 8인지 애매 | **최선의 추정** + 태그 `?` | `2027.06.26 ?` |
| 일부가 잘려서 한 자리를 못 읽음 | 태그 `s` (판독불가) + `?` — 부분 라벨은 도구가 지원 안 함 | `s ?` |
| 연도가 2자리 (`25`) | 그대로 적으면 도구가 20xx 로 해석 | `25.06.26` |
| 외국 제품이라 일/월/년 순서 같음 | 태그 `d` — 도구가 순서를 뒤집음. 확신 없으면 `d ?` | `30 12 23 d` |
| 라벨이 옆으로 누워 있음 | F1 로 화면 돌려 읽고, 태그 `r` | `25.12.20 r` |
| 이미지 자체가 화질이 나빠 글자가 작음 | 읽히면 읽고 태그 `t`, 안 읽히면 `s t` | |

원칙: **정답을 모르겠으면 `?` 를 달고 넘어간다.** 멈춰서 고민하지 않는다. `?` 는 모아서 같이 검토한다.

**태그** — 뒤에 공백으로 붙임, 여러 개 가능
`2` 병기 · `d` 일먼저 · `r` 90도 회전 · `t` 글자 너무 작음 · `b` 흐림 · `e` 각인 · `n` 키워드 없음 · `s` 판독불가 · `?` 애매

**단축키** — F1 화면 회전 · Ctrl+Z 직전 취소 · Esc 종료 (중간에 꺼도 이어서 됨)

**잘못 쳤을 때 (뒤로 가기)**
- **Ctrl+Z** → 직전 사진으로 돌아가고 아까 친 값이 입력칸에 채워짐. 고쳐서 Enter. CSV 의 그 줄은 자동으로 지워짐
- 여러 장 전으로 가려면 Ctrl+Z 를 그만큼. 중간 것들은 값이 채워져 있으니 Enter 만 치면 됨
- **창을 이미 닫았으면** → `labels/labels_block<N>.csv` 를 메모장으로 열어 그 줄을 지우고 다시 실행하면 지운 사진만 다시 뜸. 값을 직접 고쳐도 됨

## 끝나면

`labels/labels_block<N>.csv` 가 생김. 그 파일만 커밋·푸시:

```bash
git add labels/labels_block1.csv && git commit -m "labels: block 1" && git push
```

블록마다 파일이 달라 충돌 안 남. `?` 태그 단 것들은 모이면 같이 검토.
