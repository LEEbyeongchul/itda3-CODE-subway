## 절차와 이 PC 에서만 필요했던 조치

1. `python -m venv .venv` → `pip install -r requirements.txt` — 성공 (10분).
2. `bash download_weights.sh` — Windows 에서 두 번 막혀 README 가 안내하는 방법으로 넘었다. **둘 다 Windows 전용 문제이고 채점 환경(Ubuntu)과 무관하다.**
   - Windows venv 에는 `python3` 실행 파일이 없어 스크립트가 스토어 바로가기를 잡음 → `PYTHON=python` 지정 (스크립트가 지원하는 변수).
   - Windows Python 의 인증서 번들 문제 `CERTIFICATE_VERIFY_FAILED` → README 7절대로 `SSL_CERT_FILE` 을 certifi 로 지정.
3. `jupyter nbconvert --to notebook --execute predict.ipynb` — 기본 설정 1회, 가드 끔 1회.
