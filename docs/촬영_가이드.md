# 추가 데이터 촬영 가이드 — 본선용 1,000장 (9/23 ~ 9/24)

> 목적: 지금 오답의 절반이 **도트 프린터·각인 글씨 오독**이고, 규칙으로는 더 못 고친다. 진짜 어려운 글씨 사진을 학습 데이터에 넣는 게 남은 유일한 지렛대다.
> 이 사진은 **학습에만** 쓴다. 측정용 500장(블록 1~5)에는 절대 섞지 않는다. 보고서 2-1절 "추가 수집: 직접 촬영 N장" 과 가산점 증빙이 된다.

## 1. 뭘 찍나 — 인당 200장, 종류 비율을 지킬 것

| 종류 | 인당 | 어디서 | 왜 |
| --- | --- | --- | --- |
| **도트 프린터(잉크젯) 날짜** — 점으로 찍힌 글씨 | 80 | 캔 밑면, 페트병 목·바닥, 우유·요구르트 뚜껑, 과자·라면 봉지, 두부·햄 | 오답 1순위 |
| **각인·양각** — 투명·은색 위에 눌러 찍힌 글씨 | 40 | 플라스틱 용기 바닥, 캔 밑면, 유리병 | 탐지가 아예 못 잡는 유형 |
| **제조·소비 병기** — 날짜가 두 개 | 40 | 도시락·김밥·반찬·샐러드·유제품·빵 | 병기 정확도 65%로 최저 |
| **작게·멀리** — 팔을 뻗어 제품 전체가 나오게 | 40 | 아무 제품. 위 셋 중 하나를 멀리서 한 장 더 | 작은 사진(33%)이 75.8% |

- 같은 제품을 가까이 1장 + 멀리 1장 찍으면 두 종류를 한 번에 채운다.
- 선명한 일반 인쇄(잡지 글씨 같은 것)는 이미 잘 읽으니 **찍지 않는다**. 어렵게 생긴 것만.
- 한 제품당 최대 2장. 100개 제품이면 충분.

## 2. 어떻게 찍나

- 폰 기본 카메라, **날짜가 화면 가운데 오게**, 초점 맞추고(화면 터치) 찍는다. 흔들린 건 지운다.
- 대회 데이터와 같은 조건이어야 한다: 매장 조명 그대로, 플래시 끄기, 필터·보정 없음, 정사각 크롭 없음.
- 세로·가로 상관없음. 기울어져도 됨(실제 데이터도 그렇다).
- **사람 얼굴·매장 직원·가격표 전체가 나오지 않게.** 상품 뒷면만.
- 매장에서 찍기 불편하면 집에 있는 것·사 온 것으로. 냉장고·찬장에 이미 40장은 있다.
- 아이폰: 설정 → 카메라 → 포맷 → **호환성 우선**(JPG). HEIC 로 찍었으면 갤러리에서 "JPG 로 내보내기".

## 3. 등록하고 라벨링하기 (PC, 10분)

1. 폰 사진을 PC 폴더 하나에 모은다 (예: `C:/사진/소비기한`). 이름은 아무거나.
2. 저장소 폴더에서 등록 (긴 변 2,000px 로 축소하고 이름을 `x승아0001.jpg` 식으로 바꿔 `custom_photos/` 에 복사, `labels/sample.csv` 에 블록으로 등록):
   ```bash
   git pull
   python notebooks/register_photos.py --name 승아 --src "C:/사진/소비기한"
   ```
   블록 번호: 승아 16 · 서현 17 · 민섭 18 · 서영 19 · 병철 20
3. 라벨링 — 도구·규칙은 예선과 똑같다 (`labels/README.md`):
   ```bash
   python notebooks/label.py --block 16 --name 승아 --images custom_photos
   ```
   - 보이는 그대로 입력, 병기는 늦은 날짜 + 태그 `2`, 제조일자만 있으면 `NONE`, 못 읽겠으면 `s`.
   - **찍은 사람이 라벨링한다.** 실물을 봤으니 흐린 글씨도 안다. 그 지식이 라벨 품질이다.
4. 올리기 — 라벨만 git, 사진은 드라이브:
   ```bash
   git add labels/labels_block16.csv labels/sample.csv
   git commit -m "labels: 블록 16 직접 촬영 200장 (승아)"
   git push
   ```
   사진(`custom_photos/` 안의 `x승아*.jpg`)은 팀 드라이브 `본선_추가촬영/` 에 올린다. 병철이 모아서 학습 크롭을 뽑는다.

## 5. 자주 하는 실수

- 사진 파일을 git 에 올리지 않는다 (`custom_photos/` 는 .gitignore). 라벨 CSV 만.
- `label.py` 에 `--images custom_photos` 를 빼먹으면 "파일 없음" 오류.
- 같은 폴더로 `register_photos.py` 를 두 번 돌려도 된다 (이미 등록된 건 건너뜀). 새 사진을 추가하면 다시 돌리면 된다.
- 날짜가 두 개인데 어느 게 소비기한인지 모르겠으면 늦은 쪽 + `2`. 이건 규칙이다.
