## 2. 병기는 지금 어떻게 처리되나

병기 전용 처리는 없다. 모든 사진이 같은 길을 가고, 날짜가 여럿이면 **가장 늦은 날짜**를 소비기한으로 고른다(운영진 확정 규칙).

```
① 1패스: 축소본 전체 읽기 → 날짜처럼 보이는 줄을 전부 후보로
② 2패스: 후보 줄만 원본에서 잘라 다시 읽기 (3번 읽어 다수결)
   └ 유지 규칙: 2패스가 못 읽은 1패스 후보는 지우지 않고 남김
③ 한국어 2차 의견(p1det): "소비·유통·까지·EXP" 줄의 날짜를 후보에 추가
④ 선택: 가장 좋은 패턴 등급 안에서 가장 늦은 날짜
```

약점: 두 날짜가 **모두 후보에 올라와야만** 맞는다. 소비기한 줄을 못 읽으면 제조일을 답으로 내고, 더 늦은 가짜 후보가 생기면 그걸 고른다.

- 방향을 정하지 않으므로 반대 사례 `24/10/2021 07/2020` 의 `2021 07/20` 도 같은 기준으로 걸린다. 9/23 에 기각한 범위 가림 규칙(SPAN, +10/−5)의 대칭 결함이 여기서 풀린다.
