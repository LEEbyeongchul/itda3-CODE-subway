# D안(중고거래) 근거 자료 — 웹 검색 결과 (9/28 밤, 병철)

> 목적: 서현 수정안("잔여기한을 거래 정보로")의 문제 배경·분모·ROI 에 쓸 숫자.
> 숫자마다 출처와 기간을 붙였다. **기사 요약을 거친 값이라 보고서에 넣기 전에 원문을 한 번 더 열어 확인할 것.**

## 1. 가장 중요한 발견: 당근은 이미 OCR 을 쓴다

- 당근은 건강기능식품 카테고리에 **OCR 을 도입해, 건기식 문구나 인증마크가 없는 사진이 올라오면 자동으로 판독해 게시자에게 알림**을 보낸다 (농민신문 2024-07-28, SBS). 인증이 없으면 자동 삭제한다는 보도도 있다 (SBS).
- 게시 몇 초 안에 스팸·사기·불법 게시물을 머신러닝으로 거른다 (디지털투데이).
- **의미**: "플랫폼이 사진을 OCR 로 읽는다" 는 이미 현실이다. 도입 현실성(도메인 15점)의 근거가 된다. 우리 제안은 **이미 도는 OCR 이 인증마크만 보고 소비기한은 안 읽는 빈칸을 채운다** 로 말할 수 있다.
- 심사 질문 대비: "당근이 이미 OCR 을 쓰는데 새로운 게 뭐냐" → 인증마크 유무(있다/없다)가 아니라 **날짜 값**을 읽어 잔여기한을 계산해 거래 조건(건기식은 소비기한 이내)을 확인하는 것.

- 선물세트(스팸·참치·식용유·홍삼)는 **날짜가 인쇄된 미개봉 가공식품·건기식**이라 대회 데이터와 같은 종류다.
- 기사마다 스팸 증가율이 다르게 나온다(43% / 801%). 기간·지표(거래량·검색량)가 달라서다. 보고서엔 한 기사 기준으로만 쓴다.

## 4. 이 숫자로 만들 수 있는 ROI 뼈대 (가정 표시)

대상: 건기식 카테고리 (거래 조건이 명확: 미개봉, **소비기한 이내**, 연 10회·30만 원 이하). ※ 시범사업 초기(2024-05)에는 '잔여 6개월 이상'이었으나 2025-05-08 부터 '소비기한 이내'로 완화됨 (서현 조사, `docs/D안_추가조사_0928.md`).

| 항목 | 값 | 근거 |
| --- | --- | --- |
| 게시글 수 | 월 약 24,000건 (하루 약 800건) | 482,675건 ÷ 20개월 |
| 연산 비용 | 하루 800장 × 장당 약 3초 ≈ 40분 CPU | 우리 실측 (4코어). 서버 1대의 일부 |
| 소비기한 미준수 조치 | 20개월 725건 (게시글의 0.15%) | 식약처 자료 |
| 전체 위반 조치 | 20개월 14,729건 (3.05%) | 식약처 자료 |
| 사람 검토 단가 | [가정] 건당 30초 | 서영 문서 D-3 단가 |

말할 수 있는 것:

- **비용은 사실상 0 에 가깝다.** 하루 800장이면 CPU 40분이다. 당근은 이미 OCR 파이프라인을 운영한다.
- **소비기한 미준수는 전체 위반의 5%(725/14,729)뿐이다.** 소비기한만으로 모니터링 인력을 크게 줄인다고 주장하면 과장이다. 가치는 "인력 절감" 보다 **게시 전 안내(잔여기한 자동 계산) + 판매자 입력 편의 + 구매자 정보** 쪽으로 말해야 한다.
- 우리 모델은 폰 사진에서 **남은 날을 적게 읽는 경우 15.8%** 라, 기한이 지났다고 자동 차단하면 기한이 남은 정상 게시글까지 막는다. **차단 대신 "판독값 확인 요청"** 으로 해야 한다 (`docs/도메인_C1_vs_D_의견.md` 참고).

| | 이전 | 이 자료 이후 |

| 전제 (소비기한 입력란) | 미확인 | 가공식품 칸 있음(서영 캡처), 건기식은 필수 기재 |

| ROI | 없음 | 비용 ≈ 0 은 말할 수 있음. 이익은 여전히 금액으로 만들기 어려움 |
