# 제출용 초안(수정본) 검토 — 서현에게 (9/28, 병철)

> 대상: 서현이 쓴 "제출용 초안 (수정본)" 6개 항목. 전체 구성과 숫자는 실험 기록과 맞고 그대로 써도 되는 수준.
> **고칠 곳 4개 + 넣으면 좋은 것 2개.** 아래 "고칠 문장"은 그대로 복사해 써도 된다.

## 4. 그대로 두면 되는 것

- 1번 한 줄 요약, 2번 파이프라인 ①~④ 설명
- 3번 첫째(단계별 오답 진단), 셋째(틀리는 방식 설계)
- 5번의 "정확도는 안전성이 아니라 자동화율을 결정한다" 논리 — 이 초안에서 가장 좋은 문장. 발표에서도 그대로 쓸 것
- 4번의 저해상도 33% 한계 서술
