## 4. 예상 질문과 답 (질의응답 5분)

심사위원 구성(운영진 공지): ① 컴퓨터비전 교수(前 자율주행) ② 스마트 제조·물류 최적화 교수 ③ 화학 기업 출하 표시물 자동화 데이터 사이언티스트. 답은 **결론 한 문장 → 숫자 → 근거 위치** 순서로, 30초 안에.

| 시간 가드가 실제로 발동한 적이 있나? | 있다. 9/28 새 사진 389장을 돌리던 중 PC가 절전에 들어가 한 장이 2.8시간으로 잡혔고, 가드가 경량 1단계로 내려가 389장 결과 파일을 끝까지 냈다. 그 대가도 쟀다: 경량 모드로 돈 222장은 정상 모드보다 29장 덜 맞혔다(101 대 130). 대신 장당 8.0초가 1.8초로 줄었다 | 13 |

| 필드 평균이 뭔가? | 연·월·일을 따로 채점한 평균. 운영진 채점 방식이다. 완전일치는 셋 다 맞아야 1점 | 22 |

### 도메인·운영 (심사위원 ②·③ 예상)

| 질문 | 답 | 띄울 슬라이드 |
| --- | --- | --- |
| 당근이 이미 OCR 을 쓰는데 새로운 게 뭔가? | 당근 OCR 은 건기식 인증마크가 사진에 **있는지**를 본다(2024-06 도입). 우리는 같은 사진에서 소비기한 **값**을 읽고, 제조일·품목보고번호와 구분해 날짜로 확정한다. 어려운 건 읽기가 아니라 해석이고, 그게 후처리 규칙이다 | 16, 9 |
| 판매자가 어차피 확인하면 그냥 타이핑하는 것과 뭐가 다른가? | 신분증·카드번호 스캔과 같은 입력 편의다. 확신할 때만 채우니 틀린 값을 받는 판매자는 10%(확신도 0.7 기준)이고, 못 읽으면 빈칸이라 지금보다 나빠지지 않는다. 그리고 판매자가 고친 값이 공짜 라벨이 되어 자동 입력 비율이 계속 오른다 | 17 |
| 스티커를 붙여 날짜를 위조하면? | 막지 못한다. 그래서 사기 방지 장치로 제안하지 않았다. "확인됨" 대신 "판매자 사진 판독값"과 날짜 원본을 보여 주고, 원본·촬영 시각·수정 이력을 신고 시 증거로 남긴다. 악의적 위조는 기존 사후 모니터링이 맡는다 | 16 |
| 폰 사진 52%로 서비스가 되나? | 자동 입력 기준을 플랫폼이 고를 수 있다. 무조건 채우면 70%가 채워지고 21%가 틀린 값을 받는다. 확신도 0.7 이상만 채우면 45%가 채워지고 틀린 값은 10%다. 0.9 이상이면 2%. 판매자가 최종 확인하므로 틀린 값은 한 번 고치면 끝난다 | 17, 18 |
| 남은 날을 부풀려 읽으면 위험하지 않나? | 폰 사진에서 4.9%(중앙 +63일)다. 그래서 읽은 날짜가 제품 유형별 최대 기한을 넘으면 판독 불가로 처리하고, 판매자 확인을 거친다. 자동 차단·자동 통과는 하지 않는다 | 18 |
| 6개월 미만을 자동으로 막으면 되지 않나? | 폰 사진에서 남은 날을 적게 읽는 경우가 16%라, 자동 차단하면 정상 게시글을 막는다. 그래서 재확인 요청만 하고 최종 판단은 기존 검토에 둔다 | 17, 18 |
| ROI 는? | 비용은 실측이다: 하루 800장 × 장당 3초 ≈ CPU 40분, 라이선스·GPU 0. 이익은 금액으로 부풀리지 않았다. 소비기한 위반은 건기식 전체 위반의 5%(725/14,729건)뿐이라 인력 절감을 주장하면 과장이다. 가치는 잔여기한 안내·검색, 입력 편의, 기한 경과 글 자동 숨김이다 | 17 |
| 규모 숫자의 출처는? | 건기식 게시글 482,675건·위반 조치 14,729건은 2024-05~2025-12 식약처 자료(국회 의원실 제출, 2026-03 보도). 선물세트 거래량 +50% 는 당근 발표(뉴스1 2026-09-28). 일반 가공식품 게시글 수는 공개 자료가 없어 1차 대상을 건기식으로 잡았다 | 16, 17 |
| 선물세트는 날짜가 여러 개 아닌가? | 맞다. 구매자에게 중요한 건 가장 이른 날짜인데, 우리 규칙은 한 사진에서 가장 늦은 날짜(제조일과 구분하려고)를 고른다. 그래서 상품별로 따로 찍게 하고 세트 표시는 그중 가장 이른 날짜로 한다 | 18 |
| 장당 3초면 게시가 느려지지 않나? | 판매자가 제목·가격을 쓰는 동안 뒤에서 처리된다. 더 빨라야 하면 다시 읽기 단계를 끄면 되고(시간 가드 1~2단계), 그때 잃는 정확도도 재 두었다 | 13 |
| 시간 가드가 발동하면 정확도는? | 1단계(재시도 생략)는 미인식이 늘고, 2단계(다시 읽기 생략)는 다수결 효과가 빠진다. 3단계는 남은 장이 NONE이다. 정확도를 잃는 대신 0점을 피하는 장치이고, 기본 조건에서는 발동하지 않는다 | 13 |
| 공장·의약품에도 쓸 수 있나? | 읽기 → 기준값과 대조 → 예외만 사람에게, 이 구조는 같다. 공장 출하 전 날짜 인쇄 확인은 기대값(제조일 + 품목별 기한)과 대조하면 되고, 의약품은 제조번호·사용기한 형식 규칙만 바꾼다. 다만 의약품은 일련번호 바코드가 의무라 OCR 은 바코드 없는 표시면의 보조 확인으로 시작하는 게 맞다 | 19 |
| 각인·도트 인쇄는 어떻게 개선하나? | 규칙으로는 끝났다. 촬영 조건(조명 각도)과 인식기 학습 데이터가 답이다. 판매자가 고친 값과 미인식 사진의 날짜 줄이 그대로 학습 데이터가 된다 | 18 |
| 왜 직접 촬영 데이터로 재학습하지 않았나? | 학습용 글자 조각을 자동으로 확인할 수 있는 사진이 적었고, 파인튜닝 인식기가 실제로 쓰이는 곳이 500장 중 12장이라 기대 효과가 0~1장이었다. 그 데이터는 한계를 재는 시험지로 썼다 | 18 |

### 답하기 어려운 질문이 나오면

- 모르는 것은 "측정하지 않았습니다"라고 말하고, 측정한 가장 가까운 숫자를 댄다.
- 모든 수치의 예측 파일과 실험 기록이 저장소에 있다는 점을 덧붙인다 (`results/`, `docs/실험_기록.md`).
