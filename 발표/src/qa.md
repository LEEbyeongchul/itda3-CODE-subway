## 4. 예상 질문과 답 (질의응답 5분)

심사위원 구성(운영진 공지): ① 컴퓨터비전 교수(前 자율주행) ② 스마트 제조·물류 최적화 교수 ③ 화학 기업 출하 표시물 자동화 데이터 사이언티스트. 답은 **결론 한 문장 → 숫자 → 근거 위치** 순서로, 30초 안에.

| 플랫폼이 이미 OCR 을 쓰는데 새로운 게 뭔가? | 보도에 따르면 플랫폼의 OCR 은 건강기능식품 문구·인증마크가 사진에 **있는지**를 본다. 소비기한을 읽는다는 자료는 찾지 못했다. 우리는 같은 사진에서 소비기한 **값**을 읽고, 제조일·품목보고번호와 구분해 날짜로 확정한다. 어려운 건 읽기가 아니라 해석이고, 그게 후처리 규칙이다 | 16, 9 |

| 확신도 기준을 왜 0.7 로 잡았나? | 기준 없음에서 0.7 로 올리면 틀린 값 41장을 피하려고 맞는 값 58장을 포기한다(1.4 대 1). 0.7 에서 0.9 로 올리면 32장을 피하려고 78장을 포기한다(2.4 대 1). 틀린 값 하나의 비용이 맞는 값 하나의 이득의 1.4~2.4배라고 볼 때 0.7 이 맞다 | 17 |

### 답하기 어려운 질문이 나오면

- 모르는 것은 "측정하지 않았습니다"라고 말하고, 측정한 가장 가까운 숫자를 댄다.
- 모든 수치의 예측 파일과 실험 기록이 저장소에 있다는 점을 덧붙인다 (`results/`, `docs/실험_기록.md`).

## 5. 발표 전 확인

- [ ] 표지의 팀원 이름에 성을 붙일 것 (지금은 이름만 있음)
- [ ] 소비기한 칸이 필수 입력인지 게시 화면에서 확인 (보고서 남은 일 3번)
- [ ] 발표자 나누기: 1~9번(설계), 10~14번(성능), 15~20번(도메인) 3구간이 자연스러움
- [ ] 리허설에서 10분을 넘으면 9번(후처리 규칙표)은 "표는 자료로 보시고"로 줄이고, 19번(확장)은 한 문장만
