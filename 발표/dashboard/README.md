# 소비기한 판독 운영 대시보드 (시연용)

D 안(중고거래 식품·건강기능식품 게시글의 소비기한)의 전략을 화면으로 옮긴 것이다. 발표장에서는 직접 띄울 수 없으므로, 화면을 캡처하거나 녹화해 슬라이드에 넣는다.

서버가 없고 데이터는 `index.html` 안에 직접 적어 넣었다(하드코딩). 파일을 브라우저로 열면 된다.

## 화면

| 번호 | 화면 | 보여 주는 것 |
| --- | --- | --- |
| 1 | 전략 맵 | 구매자·판매자·플랫폼의 페인포인트 → 근거 → 전략 → 대시보드 지표 |
| 2 | 판매자 화면 | 촬영 → 판독 → 확인 → 게시글. 사례 5개(확신할 때, 확신이 낮을 때, 틀리게 읽었을 때, 기한이 지났을 때, 못 읽었을 때) |
| 3 | 운영 현황 | 자동 입력 기준을 바꾸면 채워지는 비율과 틀린 값이 어떻게 달라지는지 |
| 4 | 검토 큐와 기록 | 입력값과 판독값이 다른 글만 사람에게. 게시글마다 남는 판독 기록 |
| 5 | 비용과 확장 | 건당 비용, 손익분기 계산, OCR 이 있어야 되는 가치, 확장 단계 |

## 숫자의 출처

화면에 `실측` 과 `예시` 표시를 붙였다.

| 구분 | 값 | 출처 |

| 실측 | 자동 입력 기준별 비율(70.2 / 44.7 / 40.6 / 16.5%), 틀린 값(20.8 / 10.3 / 8.2 / 2.1%) | 직접 촬영 389장, `docs/본선보고서_초안_D.md` 6-2 |

직접 찍은 폰 사진의 정확도(52.4%)는 넣지 않았다.

## 캡처

```bash
python 발표/dashboard/capture.py
```

`captures/` 에 21장이 3200×1800 PNG 로 저장된다. 16:9 슬라이드에 그대로 맞는다.

특정 화면을 바로 열려면 주소 뒤에 붙인다.

| 주소 | 화면 |
| --- | --- |
| `index.html#strategy` | 전략 맵 |
| `index.html#seller/C/3` | 판매자 화면, 사례 C(A ~ E), 3단계(1 ~ 4) |
| `index.html#ops/c09/d30` | 운영 현황, 기준(none · c07 · ops · c09), 기간(d1 · d7 · d30) |
| `index.html#queue/1` | 검토 큐, 위에서 둘째 줄(0 ~ 5) |
| `index.html#cost` | 비용과 확장 |

## 녹화

판매자 화면의 `▶ 자동 재생` 을 누르면 2.6초마다 다음 단계로 넘어가며 사례 5개를 차례로 보여 준다. 브라우저를 전체 화면(F11)으로 하고 화면 녹화(Win + Alt + R)를 켠다.

## 주의

- 글꼴 Pretendard 는 인터넷에서 받아 온다. 인터넷이 없으면 PC 에 설치된 Pretendard, 없으면 맑은 고딕으로 보인다.
- 화면 색은 발표 슬라이드와 맞췄다(진한 빨강 `8B0000`, 회색 카드).
- 사진은 대회 제공 데이터에서 잘라 `img/` 에 넣었다.
