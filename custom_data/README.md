# custom_data — 직접 라벨링 데이터 (가산점 증빙)

운영진 공지(custom_data 제출 규격)에 따른 자체 구축 데이터 폴더입니다.
**라벨 정본은 `labels_all.csv` 한 파일**이고(배포 이미지 3,352장 전수), `labels/` 는 같은 내용을 라벨러별 작업 블록 15개로 나눈 원본입니다.
사진 원본은 운영진 배포 데이터(`images/000001.jpg …`)를 그대로 썼으므로 이 폴더에 이미지는 없습니다. `image_id` 로 배포 사진과 1:1 대응합니다.
데이터 구축 논리·기준은 요약서 PDF(1p 표 2, 2p 표 4)에 있습니다.

## 폴더 구조

```
custom_data/
├── labels_all.csv           # ★ 라벨 정본 — 3,352행 (image_id 순)
├── labels/                  # 블록별 원본 CSV 15개 (블록 1~10 각 100장, 11~15 각 470±1장)
│   └── labels_block1.csv … labels_block15.csv
├── review/
│   ├── review_final.csv     # 파이프라인 오답 84장 육안 재검토 결과 (라벨 오류 7장 수정 근거)
│   └── keyword_scan.csv     # 제조·포장일자만 있는 사진 한글 키워드 전수 스캔 (7장 NONE 처리 근거)
├── rules/
│   ├── 날짜_해석_규칙.md      # 모호한 날짜 해석 규칙 정본 (요약서 2p 표 4 의 원본)
│   └── 라벨링_가이드.md       # 라벨링 입력 규칙·도구 사용법·분담표·지표 정의
└── tools/
    └── label.py             # 팀이 직접 만든 라벨링 창 도구
```

## 라벨 CSV 열

| 열 | 뜻 |
| --- | --- |
| `block` | 작업 블록 번호 (1~15) |
| `labeler` | 라벨러 이름 (5명) |
| `image_id` | 배포 사진 번호 (확장자 제외, 채점 `image_id` 와 동일) |
| `file` | 파일명 |
| `raw` | **포장에 찍힌 그대로** 입력한 원문 (구분자·2자리 연도 등 형식 보존) |
| `year` `month` `day` | 정규화 값. 없으면 `NONE` |
| `final_date` | `YYYY-MM-DD`. 일 없음 `YYYY-MM-NONE`, 연도 없음 `NONE-MM-DD`, 날짜 없음 `NONE` |
| `format` | 원문 표기 형식 (예: `YYYY.MM.DD`, `DD/MM/YYYY`) |
| `tags` | `2`/`p` 병기(여러 날짜 중 선택), `d` 일/월/년, `e` 유럽식 등 (전체 목록은 `rules/라벨링_가이드.md`) |
| `ts` | 입력 시각 |

## 규모

| 항목 | 값 |
| --- | --- |
| 라벨 총량 | **3,352장 전수** |

## 사용

- 측정용 500장(블록 1~5)은 튜닝·학습에 쓰지 않고 정확도 측정에만 사용 (완전일치 84.2% / 필드평균 88.8%).
- 블록 6~15 라벨로 인식기 파인튜닝 크롭 추출 (무료 Colab T4, 비용 0원). 가중치는 GitHub Release `weights-v1`.
- 규칙 실험마다 500장에서 회복/퇴보를 세어 채택 여부 결정 (`docs/실험_기록.md`).
